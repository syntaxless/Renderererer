# Renderererer

A browser-based product rendering studio for positioning 3D models and exporting transparent PNG product shots.

## Live site

This repository deploys automatically to GitHub Pages from the `main` branch.

## Supported model formats

- GLB and GLTF (recommended for embedded materials)
- OBJ with optional MTL and texture files
- STL

The app runs entirely in the browser. Model files stay on the local device.
